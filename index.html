Troubleshooting: Script Not Working or Line Ending Errors?

Fixing Windows CRLF ($'\r') on Linux servers

If you downloaded or edited the script on Windows and transferred it to Linux, you may encounter errors like:

$ bash cleaning.sh
cleaning.sh: line 9: $'\r': command not found
: No such file or directorylocal/nginx/logs/access.log
cleaning.sh: line 95: syntax error: unexpected end of file

✅ The 2-Step Solution (dos2unix):

Option A: Using dos2unix (Recommended)
sudo apt-get install -y dos2unix
dos2unix cleaning.sh
sudo bash cleaning.sh
Option B: Instant sed (No package install)
sed -i 's/\r$//' cleaning.sh
chmod +x cleaning.sh
sudo ./cleaning.sh
