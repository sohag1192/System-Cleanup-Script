Clean Up Linux, Proxmox & Docker Bloat
Without Crashing Running Services

Over time, Linux, Proxmox, and Docker hosts accumulate gigabytes of disk bloat: systemd journals, rotated log files (.gz, .1), Docker container logs, APT package archives, and trash. If left unchecked, root partitions fill up, crashing databases and stopping active services.

Automate with Cron (One-Liner Setup & Management)

Automate cleanup without manually opening or editing crontab files. Set, customize, verify, or remove in one command!

Ubuntu / Debian Daily 3:00 AM

⚡ Instant One-Liner

Downloads to /root/log_cleanup.sh and auto-adds to crontab: 

sudo wget -O /root/log_cleanup.sh https://raw.githubusercontent.com/sohag1192/System-Cleanup-Script/main/ubuntu/log_cleanup.sh && sudo chmod +x /root/log_cleanup.sh
(sudo crontab -l 2>/dev/null | grep -v "log_cleanup.sh"; echo "0 3 * * * /root/log_cleanup.sh >> /var/log/cleanup_cron.log 2>&1") | sudo crontab -

Create an isolated system cron file instead of editing root crontab:

Check active cron entries and ensure daemon is enabled:

Troubleshooting: Script Not Working or Line Ending Errors?

Fixing Windows CRLF ($'\r') on Linux servers

If you downloaded or edited the script on Windows and transferred it to Linux, you may encounter errors like:

$ bash cleaning.sh
syntax error near unexpected token $'\r'
cleaning.sh: line 9: $'\r': command not found
: No such file or directorylocal/nginx/logs/access.log
cleaning.sh: line 95: syntax error: unexpected end of file

✅ The 2-Step Solution (dos2unix):

Method 1: Using dos2unix (Recommended)
sudo apt-get install -y dos2unix && dos2unix *.sh
Method 2: Using sed (No package install)
sed -i 's/\r$//' *.sh

Frequently Asked Questions

Everything you need to know about safe system cleanup and space optimization.

How do I safely clean disk space on an Ubuntu or Debian server? ▼

Run the one-liner command: curl -sSL https://raw.githubusercontent.com/sohag1192/System-Cleanup-Script/main/ubuntu/log_cleanup.sh | sudo bash. It vacuums systemd journals older than 7 days, safely truncates active logs to 0 bytes without deleting files, flushes APT caches, and frees gigabytes of space without crashing running services.

Does the Proxmox VE cleanup script delete VM backups or templates? ▼

No, absolutely not. proxmox/proxmox-cleanup.sh strictly protects your VM & container backup archives (/var/lib/vz/dump/), OS ISO images (/var/lib/vz/template/iso/), and container templates (/var/lib/vz/template/cache/). Only host systemd journals, rotated logs, and APT caches are cleaned.

How does the Docker cleanup script work without container downtime? ▼

docker/Docker_log.sh safely truncates active container JSON logs (*-json.log) to 0 bytes while containers are actively running. It also removes stopped containers, dangling untagged images, and build cache while leaving all persistent Docker volumes completely untouched.

How do I fix the "$'\r': command not found" error in Bash? ▼
This happens when a script has Windows CRLF line endings. To fix it, run: sudo apt-get install -y dos2unix && dos2unix *.sh or use sed without installing anything: sed -i 's/\r$//' *.sh
